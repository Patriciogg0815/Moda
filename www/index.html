Bienvenido 👋

QuéVeo te recomienda películas y series, te muestra su póster, resumen y calificación, y te dice en qué plataforma verla en tu país (o si está en cines).

Para obtener los datos usa la API gratuita de TMDB. Solo necesitas configurarla una vez:

  1. Crea una cuenta gratis en themoviedb.org.
  2. Ve a Ajustes → API y copia tu API Key o tu token de lectura.
  3. Pégala en Configuración junto con tu país y tus plataformas.
